fluxo do sistema

Usuário se cadastra / faz login → (accounts)

Navega nos eventos e ingressos → (events)

Adiciona ingressos ao carrinho → (cart)

Finaliza pedido → (orders)

Realiza pagamento → (payments)

Recebe ingresso digital (QR/PDF) → (tickets)

Recebe notificações → (notifications)

Admin vê relatórios → (analytics)

accounts/ (Usuários)

Porque todo o resto depende do login/cadastro.

Criar CustomUser com campos extras (nome, telefone, tipo de usuário: cliente / organizador / admin).

Estruturar Order e OrderItem.

Conectar com carrinho → checkout.

payments/ (Pagamentos)

Criar modelo PaymentTransaction.

Implementar integração com PagSeguro (e deixar hooks para Pix, Stripe, MercadoPago).

tickets/ (Ingressos digitais)

Geração de QRCode único.

Download do ingresso em PDF.

notifications/ (Comunicação com usuários)

Disparar email de confirmação de compra.

Enfileirar notificações (ex: "Ingresso disponível", "Evento alterado").

analytics/ (Dashboard e relatórios)
